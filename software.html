c76cr ПО для шифрования и дешифрования текста

консольная утилита, предназначенная для двустороннего преобразования текстовой информации. Программа осуществляет криптографическое кодирование исходного текста в детерминированную последовательность специальных символов (математические знаки, элементы глаголицы, иероглифы и рунического письма) и его последующее гарантированное восстановление.

Исполняемый модуль (Run.exe) — основной бинарный файл, содержащий логику компилятора и декомпилятора текстовых массивов. Развернут в нативный машинный код x86_64 с помощью утилиты Nuitka.

Динамическая библиотека (python310.dll) — встроенная системная зависимость, необходимая для корректной инициализации Python C-API в изолированной среде без установки глобального интерпретатора на целевом ПК.

Максимальный объем ввода: Система обработки строк оптимизирована под работу с массивами данных объемом до 50 стандартных текстовых строк (около 5000 символов) за один сессионный ввод. Превышение лимита может вызвать некорректное отображение в буфере консоли Windows.

Автоматическое сохранение в файл: При активации финального запроса [y/n] в интерфейсе программы, утилита автоматически генерирует выходной текстовый документ формата .txt в одной директории с исполняемым бинарником.
